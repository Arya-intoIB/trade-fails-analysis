# Trade Fails Analysis

This project was done with sample data, made up for practice. It is not real client or bank data.

## Problem
Many trades were not settling on time. I analysed 55 trades to find the causes of failed trades and which clients were most affected.

## What I did
- Cleaned the data and added Issue Category, Days Pending and Escalate columns
- Built pivot tables and charts by issue and by client
- Wrote findings and recommendations

## Key findings
- 27 of 55 trades were pending, worth $53.8M
- Compliance, approval and document delays caused 80% of pending value
- Client B had the most pending value ($27.25M)
- 19 pending trades were older than 3 days and needed escalation

## Recommendations
1. Do compliance and document checks before the trade
2. Check cash one day before settlement
3. Set time limits for approvals and escalate when missed
